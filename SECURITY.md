# Security Policy

Report security issues in this fork privately through this repository's
[Security tab](https://github.com/jumboman32/birdnet-go-plus/security/advisories)
when private vulnerability reporting is enabled. Do not post exploit details,
credentials, or private configuration in public issues.

For vulnerabilities affecting the original BirdNET-Go project, follow its
[upstream security policy](https://github.com/tphakala/birdnet-go/security/policy).

Include the affected version or commit, steps to reproduce, and the expected
impact. This fork does not promise the upstream project's response or release
schedule.
